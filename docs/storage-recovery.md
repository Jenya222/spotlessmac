# Освобождение места в SpotlessMac

## Найти причину

Откройте «Диск». Здесь показаны измеренные источники: приложения, Application Support,
контейнеры, проекты, скрытые кэши инструментов и пользовательские папки.
Нажмите на источник, чтобы посмотреть его содержимое. Рядом доступны путь и Finder.
«Добавить папку проектов» и «Добавить кэш Hugging Face» разрешают обход только явно
выбранной папки. Весь диск и домашний каталог выбрать нельзя.

Основной размер в анализе — фактический объём на диске. Внутри источника отдельно
показан логический размер. Например, Docker.raw может быть sparse-файлом: логический
размер заметно больше занятого объёма. Hard links внутри одного измерения учитываются
один раз. Разделяемые APFS extents не позволяют гарантировать экономию по сумме строк.

«Прочее и неразобранное» — остаток занятого объёма, а не размер macOS. Измерения не
воспроизводят категории системных настроек. «Недоступно» и «Не менее» означают, что
полный размер не установлен; пустая папка показывается отдельно от ошибки доступа.
Сканирование можно остановить. Предыдущие данные при отмене помечаются как не обновлённые.

## Что можно очищать

| Источник | Правило |
|---|---|
| Обычные кэши и существующие dev-кэши | Предпросмотр существующего потока очистки |
| Конкретные кэши Cursor/Claude, uv, npm | Ручной выбор; программа/инструмент должны быть закрыты |
| Hugging Face | Удаляется целый репозиторий, включая blobs; потребуется повторная загрузка |
| Зависимости и результаты сборок | Только node_modules с package.json, .build с Package.swift, build с CMakeCache.txt; ручной выбор |
| Записи Wooffoow | Завершённые самостоятельные аудиофайлы; сначала прослушивание/просмотр |
| AnythingLLM storage, Cursor/User, Claude/vm_bundles | Только просмотр; неизвестные личные данные не считаются кэшем |
| Ollama, Xcode DeviceSupport, данные симуляторов, старые настройки JetBrains | Просмотр; не включены в новую массовую очистку |
| Docker | Отдельный раздел с точечным удалением ресурсов |

Новые категории не выбираются автоматически и не входят в «Умный уход».
Большой размер или возраст не доказывает ненужность файла. Известные активные приложения,
загрузчики и инструменты сборки блокируют новую очистку. Если активность не удалось
проверить, операция также не выполняется. Проверка процессов — предосторожность,
а не гарантия от всех изменений другими программами.

Для Hugging Face отдельные snapshots не удаляются: это может оставить большие blobs
на месте или нарушить ссылки. Кэш xet пока доступен только для просмотра.
Нестандартный HF_HOME/HF_HUB_CACHE не разрешает сканирование сам по себе: выберите
соответствующую папку hub через интерфейс.

## Приложения

Раздел «Программы» сортируется по имени или общему измеренному размеру.
Разбивка показывает программу, подтверждённый кэш и данные отдельно. Неоднозначные
совпадения и общие контейнеры не входят в подтверждённый общий объём.
Личные данные/настройки не выбираются автоматически даже при точном совпадении владельца.
Поддерживаемый кэш можно очистить отдельным действием, сохранив приложение.

## Результат операции

Файловая очистка перемещает объекты в Корзину. Она продолжает занимать место.
SpotlessMac не очищает Корзину автоматически. Отчёт различает перемещённый объём
и измеренное изменение свободного места на том же томе; другие процессы могут
увеличить или уменьшить свободное место во время операции.

Docker удаляет подтверждённые ресурсы через Docker CLI без возможности восстановления
из Корзины. Тома могут хранить нужные базы даже если Docker считает их неиспользуемыми.
Тома требуют отдельного подтверждения. Перед каждой командой проверяются контекст,
использование ресурса и, для кэша сборки, builder и актуальная допустимость очистки.
Удаление Docker.raw целиком и общий prune не используются.

Сумма размеров образов не равна экономии: слои могут быть общими. Отдельно показаны
оценка Docker, локальный размер виртуального диска и изменение свободного места Mac.
Для удалённого Docker endpoint локальный виртуальный диск/экономия Mac не приписываются
удалённому серверу. Неподдерживаемый формат оценки отображается как недоступный.

## Проверка разработки

Удаление пользовательских файлов, реальных images/volumes и очистка Корзины не входят
в проверку этой доработки. Автотесты используют временные fixtures и fake trash/CLI.
В ограниченной среде testmanagerd может быть недоступен: app/test targets собираются
через Xcode build-for-testing, а доменные XCTest запускаются напрямую через xctest.


Повторяемый запуск доменных тестов (полный набор, включая политику лицензии):

```bash
python3 scripts/test-domain.py
```

Для app/UI targets:

```bash
xcodebuild -project SpotlessMac.xcodeproj -scheme SpotlessMac \
  -configuration Debug -destination 'platform=macOS' \
  -derivedDataPath /private/tmp/spotlessmac-storage-derived \
  build-for-testing CODE_SIGNING_ALLOWED=NO \
  'OTHER_SWIFT_FLAGS=$(inherited) -Xfrontend -disable-sandbox'
```

Флаг выше отключает sandbox процесса компиляторных макросов в ограниченной среде;
он не меняет права приложения и не записан в конфигурацию продукта. Для Release
используются `-configuration Release`, отдельный derivedDataPath и `build`.
Автоматическая проверка покрывает доменную логику и компиляцию UI. Ручная проверка
окна остаётся необходимой перед выпуском: GUI-служба Orca и LaunchServices в среде
разработки не позволили её провести. Код не установлен поверх пользовательского приложения.


## Отдельная сборка для ручной проверки

```bash
./scripts/build-preview.sh
```

Скрипт создаёт отдельную Debug-сборку во временной папке, подписывает пакет локально
(ad-hoc) и проверяет подпись. Путь к `.app` и журналу сборки выводится после успешной
проверки. Скрипт не устанавливает и не запускает приложение, ничего не удаляет и не
заменяет `/Applications/SpotlessMac.app`. Debug сохраняет существующий bypass лицензии.
Это локальная проверочная сборка, а не подписанный Developer ID релиз.

В ограниченной среде компиляторных макросов:

```bash
SPOTLESSMAC_DISABLE_MACRO_SANDBOX=1 ./scripts/build-preview.sh
```

После ручного открытия проверьте вкладки «Диск», «Программы», «Очистка» и «Docker»:
пути и размеры, переходы внутрь источника, отмену анализа, сортировку приложений,
невыбранные новые категории и предпросмотры. Любое подтверждение удаления отменяйте.
Доступ к защищённым папкам может быть недоступен для новой локальной подписи — тогда
приложение должно показать неполный размер/ошибку, а не известный нулевой размер.


Если Debug уже собран, можно подготовить отдельную подписанную копию без компиляции:

```bash
./scripts/build-preview.sh /private/tmp/spotlessmac-storage-derived/Build/Products/Debug/SpotlessMac.app
```

При продолжении проверки 1 октября повторная компиляция остановилась с ошибкой нехватки
места на диске. Поэтому для preview использована предыдущая Debug-сборка, для которой
прошли 91 тест и Debug/Release проверки. Локальная подпись всей копии прошла
`codesign --verify --deep --strict`; это проверка пакета, не доказательство запуска окна.
GUI-доступ к SpotlessMac инструментом был отклонён, ручная приёмка остаётся открытой.
Временные сборки и тестовые материалы сохранены согласно запрету на удаление.
