## Что это
Приложение Docker Desktop хранит образы, контейнеры и тома в одном дисковом образе: файл Docker.raw лежит в папке vms (по документации Docker, в её подпапке 0/data). Это виртуальный диск, а не набор отдельных файлов, поэтому в Finder не видно, что внутри.

## Норма
Многие программы показывают максимальный размер этого файла, а не реально занятое место: об этом предупреждает документация Docker. Поэтому файл может выглядеть огромным при умеренной реальной загрузке.

## Почему растёт
Данные копятся внутри: образы после каждой сборки и загрузки, остановленные контейнеры, тома с базами данных. По документации Docker, место на Mac освобождается только при удалении образов, а файлы, удалённые внутри работающих контейнеров, место сами не возвращают. Поэтому размер файла может не уменьшаться, даже когда внутри многое удалено.

## Что делать
Откройте вкладку «Docker» в SpotlessMac или сам Docker Desktop и удалите ненужные образы, остановленные контейнеры и неиспользуемые тома. Перед удалением тома убедитесь, что в нём нет нужных вам данных, например базы данных проекта. Лимит дискового пространства меняется в Docker Desktop: Settings → Resources → Advanced.

## Чего не делать
Не удаляйте и не переносите Docker.raw или папку vms в Finder: удаление безвозвратно стирает все контейнеры, образы и тома, а по документации Docker после переноса в Finder Docker теряет файл. Не уменьшайте лимит диска в настройках Docker, не сохранив данные: по документации Docker это удаляет текущий файл образа диска вместе со всеми контейнерами и образами.
