## Что это
ИИ-агенты создают отдельные рабочие папки для задач, временные файлы, диагностические логи и кэши. Git worktree связан с репозиторием и может содержать уникальные изменения. История сессий нужна для продолжения диалогов.

## Норма
Несколько рабочих папок могут быть нужны одновременно. Размер и возраст сами по себе не доказывают, что данные больше не нужны.

## Почему растёт
Каждая задача может создавать свою копию файлов проекта, зависимостей и сборок. Завершение диалога не всегда означает удаление его рабочей папки.

## Что делать
Откройте раздел ИИ-агенты: он показывает объём по агентам, пути и причины рекомендаций. Известные временные данные без признаков проекта доступны для ручной очистки после семи дней без изменений. Сначала закройте агент и связанные задачи, просмотрите пути и размеры. Файлы перемещаются в Корзину; место освободится после её очистки. Для крупного завершённого проекта рассмотрите проверенный архив на внешнем диске. Перенос worktree согласуйте со средствами Git или самого агента, чтобы сохранить связи.

## Чего не делать
Не удаляйте рабочую папку только потому, что она старая. Все обнаруженные Git-репозитории, проекты и истории сессий защищены от очистки в этом разделе. Проверка распознаёт Git по метаданным, но не подтверждает наличие удалённой копии или отправленных коммитов. Ошибки чтения и ссылки также требуют ручной проверки. Ассистент может объяснить результаты, но не удаляет файлы.
