## Что это
Порядок в файлах держится на трёх приёмах Finder: папки, цветные теги и смарт-папки. Файлы, которые лежат на своих местах, легче найти, и среди них видно лишнее.

## Что делать
1. Заведите простую структуру: 3–5 папок верхнего уровня («Работа», «Личное», «Проекты», «Архив») в «Документах». Новая папка создаётся через «Файл → Новая папка» или Shift-Command-N. Один файл — одно место, глубже трёх-четырёх уровней вложенность не растите.
2. Называйте файлы по схеме «дата, тема, версия», например «2026-10-03 договор аренды»: так они сортируются по времени и находятся поиском.
3. Теги: цветные теги удобны для файлов, которые относятся сразу к нескольким проектам или категориям, — Apple советует именно так.
4. Смарт-папки: выберите «Файл → Новая смарт-папка», задайте критерии (тип файла, дата открытия, слова в тексте, тег), нажмите «Сохранить». Смарт-папка сама обновляет список, а сами файлы остаются там, где лежали.
5. Личные записи — голосовые заметки, записи звонков и встреч, диктовка. По названию файла содержимое не понять. В SpotlessMac такие файлы собраны в категории «Личные записи» с пометкой «Прослушайте перед удалением». Сначала прослушайте, нужное сохраните и назовите по смыслу, остальное переместите в Корзину.

## Чего не делать
Не удаляйте записи и документы по одному названию или размеру. Не складывайте всё на рабочий стол «пока». Не дублируйте файлы по нескольким папкам — для этого есть теги.
